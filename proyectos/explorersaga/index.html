Proyecto

ExplorerSaga

Aplicación turística Android para descubrir monumentos, gastronomía y comercios de Mérida y Extremadura mediante Kotlin, Jetpack Compose, Room y OpenStreetMap.

Estado: Android funcional · Backend planificado Kotlin Android Jetpack Compose
Ver repositorio Documentación (en el repositorio) Volver a proyectos

Problema

Facilitar el descubrimiento de patrimonio y actividades locales de una manera clara y accesible para usuarios interesados en la zona.

Solución

Cliente Android nativo con Kotlin, Jetpack Compose, MVVM, Room y un mapa OpenStreetMap basado en osmdroid. Los datos actuales se cargan desde assets JSON y se persisten localmente.

Arquitectura

Arquitectura Android organizada por navegación, pantallas Compose, ViewModels y repositorio local. La separación con un backend Java/Spring Boot y una API REST es una línea de evolución planificada, no una parte presente del repositorio actual.

No existe una API REST propia en el repositorio público actual. Los datos se cargan desde assets JSON y se gestionan localmente.
