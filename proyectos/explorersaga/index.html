Proyecto

ExplorerSaga

Aplicación turística orientada a Mérida y Extremadura para descubrir monumentos, gastronomía, comercios y puntos de interés locales.

Estado: En evolución Kotlin Android Jetpack Compose
Ver repositorio Documentación Volver a proyectos

Problema

Facilitar el descubrimiento de patrimonio y actividades locales de una manera clara y accesible para usuarios interesados en la zona.

Solución

Aplicación móvil y backend orientado a datos turísticos, con enfoque en usabilidad, contenido local y evolución hacia arquitectura backend.

Arquitectura

Aplicación en evolución con base Android y estructura que va consolidando servicios backend y persistencia para datos de negocio y contenido local.
