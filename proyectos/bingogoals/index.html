BingoGoals

Tus metas convertidas en un cartón de bingo.

Cada casilla es un objetivo y al completarlos cantas línea o bingo. Nació como prototipo en Flutter y se está reconstruyendo como web React con una API NestJS.

01 El problema

Los propósitos de año nuevo se olvidan en febrero. Un formato de juego hace que apetezca volver a ellos.

02 Qué he construido

  • Migración desde un prototipo Flutter, conservado en la etiqueta flutter-prototype-final como referencia de reglas y diseño.
  • Monorepo con web React + Vite y API NestJS.
  • ESLint, Prettier, typecheck y tests en cada pull request con GitHub Actions.
