3D Cost Manager

Gestión de proyectos y presupuestos de impresión 3D.

Backend Spring Boot con un motor de cálculo de costes y un cliente Android nativo. A partir de materiales, máquinas, mano de obra, márgenes y la tarifa eléctrica real de ESIOS, genera presupuestos inmutables.

01 El problema

Calcular con precisión el coste real de una pieza impresa en 3D (material, máquina, electricidad, post-procesado y margen) y dejar un presupuesto que no cambie después de emitirlo.

05 Qué he construido

  • Motor de cálculo puro (CostCalculator) desacoplado del ORM, con BigDecimal y redondeo HALF_UP deterministas.
  • DDD táctico: agregados Project y Quote, proyectos archivados inmodificables y snapshots financieros inmutables.
  • Contrato de errores REST unificado (ApiError + GlobalExceptionHandler) sin filtrar trazas internas.
  • JWT con secreto inyectado y validado al arrancar; BCrypt para contraseñas.
  • Cliente Android con MVVM, Retrofit y sesión cifrada con EncryptedSharedPreferences (AES-256).
  • Infraestructura como código en AWS (VPC, RDS, EC2 ARM64, Parameter Store) y pipeline de GitHub Actions hacia ECR y EC2. Definida y validada en código; pendiente de aprovisionar en una cuenta real.
  • 69 tests unitarios y de integración en el backend.
