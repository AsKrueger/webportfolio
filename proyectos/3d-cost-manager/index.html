Proyecto

3D Cost Manager

Aplicación para gestionar y calcular costes relacionados con impresión 3D, con lógica de negocio para materiales, maquinaria, herramientas y presupuestos.

Estado: En evolución Java Spring Boot PostgreSQL
Ver repositorio Documentación Volver a proyectos

Problema

Necesidad de centralizar y calcular costes asociados a impresión 3D con criterios técnicos y de negocio.

Solución

Desarrollo de una aplicación que gestiona proyectos, materiales, máquinas y presupuestos con cálculo de costes y estructura backend orientada a negocio.

Arquitectura

Estructura de dominio con separación de lógica de negocio, persistencia y servicios. Evoluciona hacia una arquitectura más clara con capas, buenas prácticas y testing.

Tecnologías

  • Java
  • Spring Boot
  • PostgreSQL
  • JPA / Hibernate
  • Docker
  • JUnit
  • Mockito
  • Flyway
  • Maven
