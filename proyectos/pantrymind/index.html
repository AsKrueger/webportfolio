PantryMind

Aprovecha todos los alimentos de tu despensa.

Monorepo con API en NestJS y web en React para gestionar inventario, recetas y lista de la compra. Ya tiene registro, inicio de sesión con tokens y rutas protegidas; la lógica de producto viene después.

01 El problema

Se compra lo que ya hay en casa, otras cosas caducan sin usarse y cuesta decidir qué cocinar con lo disponible.

02 Qué he construido

  • Workspaces de npm con un único lockfile para la API y la web.
  • Autenticación con tokens y rutas protegidas en NestJS.
  • Prisma ORM sobre PostgreSQL 18 en Docker, con una base de datos separada para tests de integración.
  • Decisiones registradas en ADRs y guías de instalación para Windows y Linux.
  • CI en GitHub Actions.
