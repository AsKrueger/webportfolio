Cosplay Journal

Plataforma para cosplayers: eventos, proyectos y grupos.

Backend en Java 21 y Spring Boot 3 con arquitectura hexagonal que importa eventos de cosplay reales, gestiona proyectos (cosplans) y coordina participaciones individuales, en dúo y en grupo.

04 Qué he construido

  • Arquitectura hexagonal (ports & adapters) con el dominio desacoplado de la infraestructura.
  • Agregados con límites de consistencia e invariantes de negocio explícitos.
  • Eventos de dominio publicados en Apache Kafka.
  • Spring Security + JWT y autorización por propiedad del recurso (403 cuando no es tuyo).
  • Scraper de ListadoManga con Jsoup, sincronización idempotente, scheduler, timeouts y reintentos con backoff exponencial.
  • API REST /api/v1 documentada con OpenAPI 3 y Swagger UI.
  • Tests de integración con Testcontainers (PostgreSQL 16 y Kafka) y CI en GitHub Actions.
  • 13 ADRs documentados y 16 issues cerradas; la siguiente es integrar el cliente Android.
