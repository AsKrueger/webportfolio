PantryMind

Make the most of everything in your pantry.

A monorepo with a NestJS API and a React web app to manage pantry stock, recipes and shopping lists. Sign-up, token login and protected routes are in place; product features come next.

01 The problem

People buy what they already have, other food expires unused, and it's hard to decide what to cook with what's on hand.

02 What I built

  • npm workspaces with a single lockfile for the API and the web app.
  • Token authentication and protected routes in NestJS.
  • Prisma ORM on PostgreSQL 18 in Docker, with a separate database for integration tests.
  • Decisions recorded in ADRs and setup guides for Windows and Linux.
  • CI on GitHub Actions.
