01 The problem

Accurately calculating the real cost of a 3D-printed part (material, machine, electricity, post-processing and margin) and issuing a quote that never changes afterwards.

05 What I built

  • Pure calculation engine (CostCalculator) decoupled from the ORM, with deterministic BigDecimal and HALF_UP rounding.
  • Tactical DDD: Project and Quote aggregates, read-only archived projects and immutable financial snapshots.
  • Unified REST error contract (ApiError + GlobalExceptionHandler) that never leaks internal traces.
  • JWT with an injected secret validated at startup; BCrypt for passwords.
  • Android client with MVVM, Retrofit and an encrypted session in EncryptedSharedPreferences (AES-256).
  • Infrastructure as code on AWS (VPC, RDS, ARM64 EC2, Parameter Store) and a GitHub Actions pipeline to ECR and EC2. Defined and validated in code; not yet provisioned on a real account.
  • 69 unit and integration tests in the backend.
